```c
&spi3 {
	status = "okay";
	pinctrl-0 = <&spi3m1_cs0 &spi3m1_pins>;
	mcp2515:mcp2515@0{
		compatible = "my_mcp2515";
		reg= <0>;
		//spi-cpha;
		//spi-cpol;
		//spi-lsb-first;
		//spi-cs-high;
		spi-max-frequency = <10000000>;
		status = "okay";
	};

};
```
&spi3代表引用 其他spi3这个节点，在这个节点后面加东西，因为spi这个节点在rk3568.dtsi
但是我们要修改的是特定板子 rk3568-ddr4.。。。.dtsi 这个设备树
`pinctrl-0 = <&spi3m1_cs0 &spi3m1_pins>;`代表设置引脚复用
-0的意思是，我们设置的是default这组状态的引脚

`mcp2515:mcp2515@0`这个节点在spi3这个节点下面
`reg= <0>;`代表mcp2515的片选是0
`spi-cpha;`![[Pasted image 20260301214737.png]]
`spi-lsb-first;`加上这行代表先发低位
`spi-cs-high;`加上这行代表片选默认拉高，选中时拉低
