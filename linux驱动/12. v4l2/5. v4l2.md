写入与读取当前的format
```c
static int ov13850_get_fmt(struct v4l2_subdev *sd,
			   struct v4l2_subdev_pad_config *cfg,
			   struct v4l2_subdev_format *fmt)
{

    
}
```
这个函数的三个参数，第一个是设备本身
第二个是一个缓冲区，算是一个草稿本，防止应用层瞎改设置，比如摄像头只支持1080p，但是应用层要写入4k 有了这个草稿本，就可以以try模式写入
第三个结构体 
```c
struct v4l2_subdev_format {
    __u32 which;   // 模式：V4L2_SUBDEV_FORMAT_TRY 还是 V4L2_SUBDEV_FORMAT_ACTIVE
    __u32 pad;     // 端口号：你要问的是第几个端口？(对于单输出摄像头，通常是 0)
    struct v4l2_mbus_framefmt format; // 格式本体：宽高、色彩编码格式
};
```
对于get format 我们需要填充这个v4l2_mbus_framefmt format，然后返回
对于set 我们就需要把v4l2_mbus_framefmt format写入硬件
