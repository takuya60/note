这个驱动需要下载当前版本的内核代码进行查看

## 找vivid的源码
查看当前内核版本号
`uname -a`
然后去linux官网下载对应的内核源码`https://www.kernel.org/pub/linux/kernel/`
如果是4.10，目录应该是`drivers/media/platform/vivid`
但是我这里用的是5.15，应该是`drivers/media/test-drivers/vivid/`
然后打开makefile进行修改
```c
KERN_DIR = /usr/src/linux-headers-5.15.0-76-generic
vivid-objs := vivid-core.o vivid-ctrls.o vivid-vid-common.o vivid-vbi-gen.o \
				vivid-vid-cap.o vivid-vid-out.o vivid-kthread-cap.o vivid-kthread-out.o \
				vivid-radio-rx.o vivid-radio-tx.o vivid-radio-common.o \
				vivid-rds-gen.o vivid-sdr-cap.o vivid-vbi-cap.o vivid-vbi-out.o \
				vivid-osd.o vivid-cec.o vivid-touch-cap.o vivid-kthread-touch.o\
				vivid-meta-cap.o vivid-meta-out.o

# 外部模块编译必须强制指定为 obj-m
# 编译进内核镜像是obj-y
obj-m := vivid.o

all:
	make -C $(KERN_DIR) M=$(shell pwd) modules

clean:
	make -C $(KERN_DIR) M=$(shell pwd) clean
	rm -rf modules.order
```
