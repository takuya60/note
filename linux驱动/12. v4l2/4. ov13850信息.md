本文档基于 OV13850-G04A 数据手册整理，针对驱动开发所需的关键引脚配置、寄存器说明、初始化流程等核心信息进行汇总。

## 一、关键控制引脚配置

OV13850 有两个核心的硬件控制引脚，用于复位、待机和电源管理：

### 1. XSHUTDOWN（Pad 46）

- **功能**：硬件复位引脚，低电平有效
    
- **特性**：
    
    - 拉低该引脚会强制触发完整的硬件复位，清空所有寄存器并恢复为默认值
        
    - 引脚内置下拉电阻
        
    - 复位释放后，需要至少 **2ms 的稳定等待时间**，等待内部电路初始化完成
        
- **上电约束**：该引脚的上升沿（从低到高）必须在所有电源（AVDD、DOVDD、DVDD）都稳定之后才能发生，否则会导致上电异常。
    

### 2. PWDNB（Pad 47）

- **功能**：硬件待机引脚，低电平有效
    
- **特性**：
    
    - 拉低该引脚会触发硬件待机模式，停止内部设备时钟、复位内部计数器，但**会保留所有寄存器的配置值**
        
    - 引脚内置上拉电阻
        
    - 硬件待机模式下功耗极低，可达到最低功耗状态
        
- **说明**：通常驱动开发中，推荐仅使用其中一个引脚做 GPIO 控制，另一个直接接 DOVDD（高电平），避免两个引脚同时控制带来的时序复杂度。
    

## 二、电源上下电时序

OV13850 对电源上电顺序有严格要求，推荐的标准配置为：**XSHUTDOWN 用 GPIO 控制，PWDNB 接 DOVDD**，对应的时序如下：

### 2.1 上电流程

1. 先上电 DOVDD（I/O 电源，1.8V/2.8V）
    
2. 再上电 DVDD（核心电源，1.2V）
    
3. AVDD（模拟电源，2.8V）可以与前两个电源任意顺序上电
    
4. 等待所有三个电源都稳定之后，将 XSHUTDOWN 引脚从低电平拉高
    
5. 等待至少 2ms 的复位稳定时间，之后即可通过 SCCB（I2C 兼容）接口配置寄存器
    

### 2.2 下电流程

1. 首先通过 SCCB 命令将传感器设置为**软件待机模式**，等待传感器停止 MIPI 数据输出
    
2. 将 XSHUTDOWN 引脚拉低，进入硬件复位 / 低功耗状态
    
3. 关闭 DVDD 核心电源
    
4. 最后依次关闭 DOVDD 和 AVDD 电源（顺序无严格要求）
    

## 三、驱动开发核心寄存器

以下是驱动开发中必须配置 / 使用的关键寄存器，所有寄存器均为 16-bit 地址，通过 SCCB 接口访问：

### 3.1 系统控制寄存器

|   |   |   |
|---|---|---|
|地址|寄存器名|位定义与功能说明|
|`0x0100`|MODE_SELECT|Bit [0]：工作模式选择 - 0：软件待机模式 - 1：流传输（Streaming）模式，启动图像输出|
|`0x0102`|FAST_STANDBY|Bit [0]：快速待机配置 - 0：等待帧消隐期（Vblank）再进入待机 - 1：立即进入待机|
|`0x0103`|SOFTWARE_RST|Bit [0]：软件复位，写 1 即可触发软件复位，无需操作硬件复位引脚|
|`0x3008`|PAD_SEL2|引脚功能复用配置，用于配置 GPIO、VSYNC 等引脚的功能映射|

### 3.2 时钟与 PLL 配置寄存器

OV13850 内置两个 PLL，用于将外部输入时钟（6~64MHz）倍频到内部 120MHz 系统时钟，这是传感器正常工作的基础：

- PLL1 寄存器组：`0x0300 ~ 0x030A`
    
- PLL2 寄存器组：`0x3600 ~ 0x3615`
    
- 配置说明：需要根据外部输入时钟（如常用的 24MHz），配置 PLL 的倍频、分频参数，最终得到 120MHz 的内部系统时钟。
    

### 3.3 MIPI 接口配置寄存器

用于配置 MIPI 输出的参数，适配主机的 MIPI 控制器：

|   |   |   |
|---|---|---|
|地址|寄存器名|功能说明|
|`0x300F`|MIPI_SC|MIPI 基础配置： - Bit [4:3]：输出位宽，01 对应 10-bit RAW 输出（该传感器默认输出格式） - Bit [1:0]：MIPI 通道数配置，支持 1/2/4 lane|
|`0x3010`|MIPI_PHY_H|MIPI PHY 高压参数配置，用于调整 slew rate、共模电压等 PHY 时序参数|
|`0x3011`|MIPI_PHY_L|MIPI PHY 低压参数配置，调整驱动能力、低功耗模式参数|
|`0x4800 ~ 0x4853`|MIPI_TOP 寄存器组|MIPI 顶层控制寄存器，包含 lane 映射、速率配置等高级参数|

### 3.4 曝光与增益控制寄存器

用于实现 AE（自动曝光）、AGC（自动增益）功能，是摄像头动态调整的核心：

#### 曝光控制

|   |   |
|---|---|
|地址|功能说明|
|`0x37C5 ~ 0x37C7`|曝光时间配置，24bit 寄存器，单位为 256 个系统时钟周期 - 最小曝光时间：0x000000 - 最大曝光时间：0xFFFFFF，120MHz 时钟下最大可达 35.79s|

#### 增益控制

|   |   |
|---|---|
|地址|功能说明|
|`0x350B`|长曝光模拟增益，最大支持 16x 模拟增益，用于长曝光场景的增益调整|
|`0x350F`|短曝光模拟增益，用于 HDR 场景的短曝光增益调整|
|`0x5502 ~ 0x5504`|数字增益配置，用于模拟增益达到上限后的额外数字增益调整|

### 3.5 白平衡控制寄存器

用于实现手动 / 自动白平衡，调整 R/G/B 通道的增益：

|   |   |
|---|---|
|地址|功能说明|
|`0x5057`|红色通道白平衡增益，12bit 寄存器，0x400 对应 1x 增益|
|`0x5059`|绿色通道白平衡增益，12bit 寄存器，0x400 对应 1x 增益|
|`0x505A`|蓝色通道白平衡增益，12bit 寄存器，0x400 对应 1x 增益|

### 3.6 批量配置寄存器（Group Hold）

|   |   |   |
|---|---|---|
|地址|寄存器名|功能说明|
|`0x3200 ~ 0x3213`|Group Hold 寄存器组|用于实现寄存器的批量更新： 1. 先打开 Group Hold，此时所有寄存器配置不会立即生效 2. 批量写入所有需要修改的寄存器 3. 关闭 Group Hold，所有配置会同时生效，避免中间状态导致的图像异常|

### 3.7 OTP 校准寄存器

OV13850 内置 8Kbit OTP 存储空间，用于存储模块的校准数据（如镜头 shading 校准、缺陷像素校准等）：

- OTP 控制寄存器：`0x3D80 ~ 0x3D91`
    
- 上电后可以通过配置这些寄存器，将 OTP 中存储的校准数据加载到传感器寄存器中，提升图像质量。
    

## 四、驱动初始化标准流程

1. **硬件上电**：按照上述上电顺序完成电源上电，拉高 XSHUTDOWN 并等待 2ms 稳定时间
    
2. **SCCB 初始化**：初始化 I2C/SCCB 接口，确认可以正常读写传感器寄存器，传感器从地址为：
    
    1. SID=0 时：写地址 `0x20`，读地址 `0x21`
        
    2. SID=1 时：写地址 `0x6C`，读地址 `0x61`
        
3. **加载 OTP 校准**：配置 OTP 寄存器，加载模块的校准数据
    
4. **PLL 配置**：配置 PLL 参数，将外部时钟倍频到 120MHz 内部系统时钟
    
5. **MIPI 配置**：配置 MIPI 通道数、位宽、PHY 参数，适配主机端
    
6. **时序与分辨率配置**：配置输出图像的分辨率、裁剪窗口、帧频等参数
    
7. **ISP 功能配置**：使能缺陷像素校正（DPC）、镜头 shading 校正（LENC）、黑电平校正（BLC）等 ISP 功能
    
8. **初始曝光增益配置**：设置初始的曝光时间、模拟增益、白平衡增益
    
9. **批量生效配置**：
    
    1. 打开 Group Hold
        
    2. 将 `0x0100`（MODE_SELECT）的 Bit0 置 1，切换到流模式
        
    3. 关闭 Group Hold，所有配置同时生效，传感器开始输出 MIPI 图像数据
        

## 五、待机与唤醒流程

### 进入待机

1. 将 `0x0100` 的 Bit0 置 0，进入软件待机模式，传感器停止输出数据
    
2. 如果需要更低功耗，可以拉低 XSHUTDOWN 引脚进入硬件复位待机
    

### 唤醒

1. 如果是硬件待机，拉高 XSHUTDOWN，等待 2ms 稳定时间
    
2. 如果是软件待机，直接将 `0x0100` 的 Bit0 置 1，即可快速恢复流输出，无需重新配置所有寄存器
