### probe函数
首先对初始化设备数量进行约束，函数是clamp_t
然后是核心函数vivid_create_instance
### vivid_creat_instance
首先先分配一块内存
```c
sturct vivid_dev *dev;
dev=kzalloc(sizeof(*dev), GFP_KERNEL)
// kzalloc是用来分配内存的，相比于kmalloc会自动进行清零
// 这里的第二个参数常用是GFP_KERNEL，代表可堵塞。GFP_ATOMIC不可堵塞
```
然后进行注册v4l2_device
```c
ret = v4l2_device_register(&pdev->dev, &dev->v4l2_dev);
// vivid_dev里面有个成员是v4l2_device
```
