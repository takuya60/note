摄像头的数据传输有三个环节
首先是sensor也就是摄像头本身，这个是挂载在i2c下面的，可以通过i2c去控制分辨率等
sensor把数据通过差分mipi线传给csi 也就是mipi-csi
然后csi再把sensor的数据给到处理器里面的isp(图像信号处理器)
所以设备树修改时，也就是需要修改这三部分
## ISP
```c
&rkisp {
	status = "okay";
};
&rkisp_mmu {
	status = "okay";
};
&rkisp_vir0 {
	status = "okay";

	port {
		#address-cells = <1>;
		#size-cells = <0>;

		isp0_in: endpoint@0 {
			reg = <0>;
			remote-endpoint = <&csidphy_out>;
		};
	};
};
```
`rkisp_mmu和rkisp`直接引用节点并且使能就行了，我们需要配置的是`rkisp_vir0`虚拟通道0
port是节点
isp_in只是一个lable，摄像头数据的传输，是在不同的endpoint之间进行传输的
`remote-endpoint = <&csidphy_out>;`这一行，就是把csi那边的out的endpoint和这里的in相连，也就是由csi把数据传给isp
## CSI
```c
&csi2_dphy_hw {
	status = "okay";
};
// 这里看名字可以看出来，是使能了芯片的csi2硬件(hardware)
&csi2_dphy0 {
	status = "okay";

	ports {
		#address-cells = <1>;
		#size-cells = <0>;
		port@0 {
			reg = <0>;
			#address-cells = <1>;
			#size-cells = <0>;

			mipi_in_ucam0: endpoint@1 {
				reg = <1>;
				remote-endpoint = <&imx335_out>;
				data-lanes = <1 2 3 4>;
			};
			mipi_in_ucam1: endpoint@2 {
				reg = <2>;
				remote-endpoint = <&imx415_out>;
				data-lanes = <1 2 3 4>;
			};
			mipi_in_ucam2: endpoint@3 {
				reg = <3>;
				remote-endpoint = <&ov13850_out>;
				data-lanes = <1 2 3 4>;
			};
		};
		port@1 {
			reg = <1>;
			#address-cells = <1>;
			#size-cells = <0>;

			csidphy_out: endpoint@0 {
				reg = <0>;
				remote-endpoint = <&isp0_in>;
			};
		};
	};
};
```
data-lanes代表差分信号线数量

## i2c
```c
&i2c4{
ov13850: ov13850@10 {
		compatible = "ovti,ov13850";
		status = "okay";
		reg = <0x10>;
		clocks = <&cru CLK_CIF_OUT>;
		clock-names = "xvclk";
		power-domains = <&power RK3568_PD_VI>;

		/* conflict with csi-ctl-gpios */
		reset-gpios = <&gpio4 RK_PB4 GPIO_ACTIVE_HIGH>;
		pwdn-gpios = <&gpio4 RK_PB5 GPIO_ACTIVE_HIGH>;
		pinctrl-names = "rockchip,camera_default";
		pinctrl-0 = <&cif_clk>;
		rockchip,camera-module-index = <0>;
		rockchip,camera-module-facing = "back";
		rockchip,camera-module-name = "ZC-OV13850R2A-V1";
		rockchip,camera-module-lens-name = "Largan-50064B31";

		port {
			ov13850_out: endpoint {
				remote-endpoint = <&mipi_in_ucam2>;
				data-lanes = <1 2 3 4>;
			};
		};
	};
};
```
- `clocks = ...`：向 RK3568 的时钟控制单元（CRU）申请，把 `CLK_CIF_OUT` 这个物理时钟引脚分配给我用。
- `clock-names = "xvclk";`：给这个时钟起个外号叫 `xvclk`，因为底层的 C 代码驱动里，写死了要去找名字叫 `xvclk` 的时钟。
- `power-domains`：电源域。告诉系统，摄像头属于 `VI` (Video Input) 电源域，系统休眠时可以把它断电省电。
- **`reset-gpios` 和 `pwdn-gpios`**：定义复位和掉电引脚。`<使用GPIO4这一组的，PB4引脚，高电平触发动作>`。
