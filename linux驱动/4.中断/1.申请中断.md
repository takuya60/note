在linux里面申请中断，要使用`request_irq` 这个函数，第一个参数是软件中断号，软件中断号是linux系统分配好的，假如要申请一个GPIO中断，那就要用`gpio_to_irq`来获取irq，也就是软件中断号。
第二个参数是中断处理函数，其返回类型是irqreturn_t
`typedef irqreturn_t (*irq_handler_t)(int, void *);
// 这是中断处理函数的定义`

这是irqreturn_t，如果需要在中断里面的某个操作结果来判断返回是否成功，就可以用IRQ_RETVAL
![[Pasted image 20260214203007.png]]
比如
```C
irqreturn_t my_isr(int irq, void *dev_id) { 
	int result = check_hardware(); 
	return IRQ_RETVAL(result); 
}
```
第三个参数是中断标志，也就是上升沿触发，下降沿触发等
