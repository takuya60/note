## 1. 为何要使用
如果不用mmap，用户空间如果需要从内核空间读取数据，需要read等
内核从用户空间拿数据，需要write，或者copy from user
mmap，本质上是一块物理内存同时指向两处

## 2.如何使用

### 2.1应用层使用
```c
int fd;
char *buf;
fd = open("dev/dev0",O_RDWR) ;
if(fd<0){
	printf("can not open file");
	return -1;
}
buf = mmap(NULL,1024*8,PROT_READ|PROT_WRITE,MAP_SHARED,fd,0);
```
#### mmap函数讲解
- param1 表示内存的开始地址，如果填写NULL，表示由内核决定
- param2 表示内存空间的大小
- param3 表示映射之后的空间可读可写
- param4 可填`MAP_SHARED`或`MAP_PRIVATE`
`MAP_SHARED`：多个`APP`都调用`mmap`映射同一块内存时, 对内存的修改大家都可以看到。就是说多个`APP`、驱动程序实际上**访问的都是同一块内存**。
`MAP_PRIVATE`：创建一个`copy on write`的私有映射。当`APP`对该内存进行修改时，其他程序是看不到这些修改的。就是当`APP`**写内存时, 内核会先创建一个拷贝给这个**`APP`，这个拷贝是这个`APP`私有的, 其他APP、驱动无法访问。

```c
	unsigned long phy = virt_to_phys(kernel_buf);

    /* map */
    if(remap_pfn_range(vma, vma->vm_start, phy>>PAGE_SHFIT,
                      vma->vm_end - vma->start, vma->vm_page_prot)){
	 printk("mmap remap_pfn_range failed\n");
    return -ENOBUFS;
	 }
	 
	 return 0;
}


static struct file_operations my_ops = {
	.mmap = my_mmap,
}
```
