应用程序需要做的
- 注册信号处理函数
- 设置能够接收这个信号的进程
- 开启信号驱动IO，通常使用fcntl的F_SETFL
### 驱动程序
1.定义fasync函数，当应用程序开启信号驱动IO的时候，会触发这个函数
这个也是在file opration里面实现的
2.在fasync里面再调用fasync_helper函数来操作fasync_struct结构体
3.在实际的操作之后，使用kil_fasync()来给应用层发送信号

信号驱动的和核心是fasync 也就是 **File ASYNCronous**（文件异步通知）
在驱动里定义一个
fasync_struct结构体
这个结构体相当于是记录了哪些进程需要收到信号

然后应用层通过
![[Pasted image 20260209152943.png]]
这三步，第一步注册信号处理函数
第二步相当于把自己设置为这个fd对应的文件所发送信号的接收者
第三步是触发驱动里面的.fasync函数，把自己添加到驱动要通知的名单里面

驱动层
.fasync也是属于file opration结构体的
这个是固定格式，记住就行， fasync_helper会自动把触发.fasync函的进程加到fasync_struct结构体里面
```c
static int m_fasync (int fd, struct file *file, int on)
{
    struct m_dev *dev_test =(struct m_dev *)file->private_data;
    // 这里是规定格式
    return fasync_helper(fd,file,on,&dev_test->m_fasync_struct);
}

```

最后，再进行通知
第一个参数是fasync_struct结构体，
第二个参数是要发送的信号
POLL_IN表示可以可读 POLL_OUT表示可写
```c
    kill_fasync(&dev_test->m_fasync_struct,SIGIO,POLL_IN);
```
