# 问题三求解结果整理

## 1. 模型与求解方法

问题三在问题二的基础上，加入了电池储能系统（BESS）和冷却系统惯性约束，因此模型不再是逐小时独立调度，而是一个带跨时段状态变量的动态优化问题。

本文采用 Gurobi 对该问题进行求解，设置 `NonConvex = 2` 以允许模型中的双线性处理量约束参与求解。模型中同时包含：

- GPU 负载变量 $x_t$；
- 数据传输速率变量 $y_t$；
- 实际冷却功率变量 $z_t$；
- 电池充放电功率变量 $p_t^{ch}, p_t^{dis}$；
- 电池荷电状态变量 $s_t$；
- 充放电状态二进制变量 $b_t$。

---

## 2. 最优求解结果

Gurobi 求得的最优日电费为：

$$
C_{\min}=84.3776\text{ 元}
$$

对应的日处理量为：

$$
Q=1{,}920{,}000
$$

恰好满足题目要求的最低日处理量。

同时，模型的主要约束均被满足：

| 约束项 | 结果 |
|---|---|
| 日处理量约束 | PASS |
| 冷却需求约束 | PASS |
| 冷却变化率约束 | PASS |
| SOC 下限约束 | PASS |
| 电网购电非负约束 | PASS |

---

## 3. 关键状态量结果

### 3.1 电池状态

- 初始 SOC：16.0 kWh
- 终止 SOC：8.0 kWh
- 充电总量：24.0 kWh
- 放电输出总量：28.8 kWh

这说明电池在低电价时段充电，并在高电价时段放电，起到了明显的削峰填谷作用。

### 3.2 冷却功率

- 冷却功率最大变化幅度：0.2 kW/h
- 说明冷却惯性约束被严格满足

冷却功率不再能像问题二那样随 GPU 负载瞬时变化，而是呈现明显平滑特征。

### 3.3 电网购电量

电网购电总量为：

$$
91.44\text{ kWh}
$$

说明储能系统在一定程度上替代了高电价时段的电网供能。

---

## 4. 分时调度特征

从每小时调度结果可以观察到以下规律：

1. 数据传输速率 $y_t$ 基本维持在 $1200\text{ Mbps}$，说明在当前模型下，提高传输速率的边际成本较低，且有利于完成日处理量；
2. GPU 负载 $x_t$ 呈现较平滑的变化趋势，不再出现问题二中那种大幅跳变；
3. 电池在谷时段和部分平时段进行充电，在峰时段放电；
4. 冷却功率随时间逐步变化，符合惯性约束的要求。

---

## 5. 为什么加入约束后电费反而下降

问题三的结果中，最优日电费从问题二的 105.7600 元下降到了 84.3776 元，看起来“约束更多，电费却更少”，但这并不矛盾，原因在于：

### 5.1 问题三不是单纯加约束，而是新增了储能资源

如果只加入冷却惯性约束，最优电费通常不会下降，反而可能升高。  
但问题三同时引入了电池储能系统（BESS），这相当于新增了一个可以跨时段调节能量的资源。

电池允许系统：

- 在谷电价时充电；
- 在峰电价时放电；
- 用低价电替代高价电网购电。

因此，虽然约束更多了，但**可利用的调度手段也更多了**，最终总电费反而可能降低。

### 5.2 目标函数只统计电费，不计电池折旧

本模型的目标函数只考虑电网购电费用，没有计入：

- 电池寿命损耗；
- 充放电折旧成本；
- 电池循环衰减成本。

因此，模型会倾向于尽可能利用电池来削减峰时电费。  
这也是问题三电费低于问题二的直接原因。

### 5.3 终止 SOC 没有回到初始值的要求

题目只要求终止 SOC 不低于 20%，并没有要求恢复到初始值 40%。  
这意味着模型可以合理消耗一部分初始电量，从而进一步减少当天高电价时段的购电支出。

## 6. 与问题二对比

| 指标 | 问题二 | 问题三 |
|---|---:|---:|
| 最优日电费 | 105.7600 元 | 84.3776 元 |
| 日处理量 | 1,920,000 | 1,920,000 |
| 是否有 BESS | 否 | 是 |
| 是否有冷却惯性 | 否 | 是 |
| 冷却变化率约束 | 无 | 0.2 kW/h |
| SOC 变化 | 无 | 16.0 → 8.0 kWh |

问题三相较于问题二节省：

$$
105.7600-84.3776=21.3824\text{ 元}
$$

节约比例为：

$$
\frac{21.3824}{105.7600}\times100\%\approx20.21\%
$$

---

## 7. 结论

问题三的最优策略可以概括为：

- 通过电池储能系统在谷时段充电、峰时段放电；
- 在满足冷却惯性约束的前提下，尽量平滑调整 GPU 负载与冷却功率；
- 通过储能削峰填谷，降低高电价时段的电网购电量；
- 最终实现日电费 84.3776 元，较问题二降低 21.3824 元。

这一结果说明，在不计电池折旧成本的情况下，储能系统对实验室节能降费具有明显价值。
