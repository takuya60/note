好问题！先澄清一下：**你目前的闭环控制器并不是完整的 PID，而是一个纯 I（积分）控制器**。我们故意只用了 I，没有引入 P 和 D。让我解释你目前有哪些"旋钮"以及怎么调。

---
### 你目前的可调参数一览

都在 stim_service.h 里：

|宏|当前值|作用|类比|
|---|---|---|---|
|`STIM_LOOP_TOLERANCE_UA`|500|**死区**：误差在 ±500uA 以内不做调节|方向盘的"虚位"|
|`STIM_LOOP_MAX_STEP_UA`|2000|**单次最大步长**：每 50ms 最多调 2mA|油门踏板的最大行程|
|K_i（写死在代码里）|`error / 10`|**积分增益**：误差的 10% 作为步长|油门踩多深|

而在 stim_service.c 的 
handle_closed_loop() 里，核心就是这一行：

c

int32_t step = error / 10;  /* K_i ≈ 0.1 */

### 为什么只用了 I，没用 P 和 D？

|PID 分量|作用|为什么不用|
|---|---|---|
|**P（比例）**|误差越大，调得越猛|在电刺激中，"猛调"就是突然加大电流。人体对此非常敏感，超调一下就是一次明显的电击感。P 太大有安全风险|
|**I（积分）**|持续小步逼近目标|✅ 这正是我们在用的。每 50ms 慢慢爬，平滑安全|
|**D（微分）**|预测趋势，提前刹车|ADC 峰值本身就有噪声波动，微分会把噪声放大，导致输出疯狂抖动|

所以你的控制器本质是：**带死区和步长限幅的增量式 I 控制器**。

---

### 怎么调参（等硬件到手后）

#### 步骤 1：先确认 ADC 校准正确

stim adc init

stim adc start

stim adc show

确保 `peak_pos_uA` 的数值在合理范围内。如果读出来的值与实际电流偏差很大，先调 
stim_adc_set_calibration()。

#### 步骤 2：开启闭环，观察日志

把 `STIM_LOOP_ENABLED` 改为 `1`，重新编译烧录。 启动刺激后，终端会持续打印：

[SVC] LOOP: target=20000 actual=15000 spi_amp=22000

[SVC] LOOP: target=20000 actual=17500 spi_amp=23000

[SVC] LOOP: target=20000 actual=19800 spi_amp=23200

（误差进入死区，停止打印，稳定了）

#### 步骤 3：根据现象调参

|现象|原因|怎么调|
|---|---|---|
|**爬升太慢**（要好几秒才到目标）|K_i 太小 或 MAX_STEP 太小|把 `error / 10` 改成 `error / 5`（K_i = 0.2），或增大 `MAX_STEP_UA`|
|**到达目标后来回抖动**|死区太小|增大 `TOLERANCE_UA`，比如从 500 改到 1000|
|**超调了**（实际电流冲过目标后又回来）|K_i 太大|把 `error / 10` 改成 `error / 20`（K_i = 0.05），或减小 `MAX_STEP_UA`|
|**永远到不了目标**（差一点点）|死区太大|减小 `TOLERANCE_UA`|

#### 调参的经验法则

> **先保守（K_i 小、MAX_STEP 小），确认安全后再逐步增大激进度。**

电刺激领域，宁可"慢一点到达目标"，也不能"快速超调电击一下"。所以一开始建议用 `error / 20`（极保守），确认不超调后再慢慢加大到 `error / 10` 甚至 `error / 5`。

如果你后续需要引入 P 项来加快响应速度，我们可以再加，但 D 项在这个场景下大概率永远不需要。
