# FFES — 功能性电刺激控制系统

基于 **STM32H7 + RT-Thread** 的多通道可编程功能性电刺激 (FES) 控制系统。
## 系统架构

```

┌───────────────────────────────────────────────┐

│  ┌────────────┐  ┌────────────┐  ┌──────────┐ │

│  │ MSH Shell  │  │  CAN 总线  │  │ UI (TBD) │ │

│  └─────┬──────┘  └─────┬──────┘  └────┬─────┘ │

│        └───────┬───────┘               │       │

│  ┌─────────────────────────────────────▼─────┐ │

│  │        服务层 stim_service (消息队列)      │ │

│  └──┬──────────────┬──────────────┬──────────┘ │
```

### 硬件组成

| 主控板         | STM32H7 | RT-Thread 调度、参数管理、多源输入 |
| 电刺激         |  SPI4  | 电刺激波形生成 |
| 保护模组板   |  I2C2 |  过流安全保护 |
| 复用模组板   | SPI1 菊花链 | 32 通道电极选择 |

## 快速开始

### 1. 编译环境  

- RT-Thread Studio 或 Keil MDK

- 芯片包：STM32H7xx

- 需使能组件：SPI、I2C、CAN、USB CDC

### 2. 初始化流程

系统上电后 `main.c` 自动执行：
等待 USB CDC (`vcom`) 就绪，切换 Shell 终端
### 3. MSH 命令

```bash

stim init                        # 初始化服务

stim amp  <pos_uA> <neg_uA>     # 设置幅值 (uA)

stim time <freq> <pos> <neg> <dead>  # 设置时间参数 (Hz/us)

stim ch   <channel> <0|1>       # 开关单通道电极 (0~31)

stim chmask <chip> <hex> <0|1>  # 按掩码批量设置电极

stim chclear                    # 清除所有电极

stim start                      # 开始刺激

stim stop                       # 停止刺激

stim status                     # 查看状态/参数/电极

stim reset                      # 复位故障

```

**示例**:

```bash

stim init

stim amp 5000 5000              # 正/负向各 5mA

stim time 50 200 200 50         # 50Hz, 脉宽200us, 死区50us

stim ch 0 1                     # 打开通道 0

stim start

```
## 通信协议

### SPI 控制包 (H7 → M0, 固定 20 字节)
  

| 偏移 | 字段 | 说明 |

|------|------|------|

| 0 | `head` | `0xAA` |

| 1 | `cmd` | `0x01`=START, `0x02`=STOP, `0x03`=AMP, `0x04`=TIME |

| 2 | `len` | 有效载荷长度 |

| 3~17 | `payload` | 参数 (未用部分填 0) |

| 18~19 | `crc16` | CRC16-Modbus 校验 (小端) |

  

### CAN 协议 (上位机 ↔ H7)
  

| ID | 方向 | 用途 |

|----|------|------|

| `0x100` | 上位机 → H7 | 命令帧 (`data[0]` = 命令码) |

| `0x200` | H7 → 上位机 | 反馈帧 (`data[0]` = 事件码) |

  

命令码：`0x01`=START, `0x02`=STOP, `0x03`=AMP, `0x04/05`=TIME, `0x0F`=RESET, `0x10`=CH_SET, `0x11`=CH_MASK, `0x12`=CH_CLEAR

## 状态机  

```

IDLE ──init──► READY ──start──► RUNNING ──stop──► READY

                 ▲                  │

                 │              过流触发

                 └──reset──── FAULT ◄┘

```

## 扩展新输入源

只需 3 步即可接入新的控制方式（如 UI、蓝牙等），无需修改服务层和驱动层：

```c

// 1. 创建 input/stim_xxx.c

// 2. 构造消息

stim_msg_t msg = { .cmd = STIM_CMD_START };

// 3. 投入队列

stim_service_send_cmd(&msg);

```
