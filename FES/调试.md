### 调试工作流（从底层到顶层）

| 阶段                  | 操作                                                                       | 通过标准                                                    |
| ------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| **① MAX14802 电极驱动** | `max14802_test` 命令验证电极通断                                                 | 设置某个通道为 ON，用万用表量到对应引脚导通                                 |
| **② FES 刺激驱动**      | `stim init` → `stim start`                                               | 示波器看到 FES_OUT_H / FES_OUT_L 有波形输出                       |
| **③ ADC 底层驱动**      | `adc_test init` → `adc_test start` → `adc_test dump`                     | 不刺激时，ADC 值稳定在 **~32768** 附近（1.65V偏置）；刺激时能看到明显的尖峰        |
| **④ ADC 服务层**       | `stim adc init` → `stim adc start` → `stim adc show`                     | `peak_pos` 和 `peak_neg` 能正确反映脉冲方向和大小，`peak_pos_uA` 数值合理 |
| **⑤ ADC 校准**        | 万用表串联测实际电流，对比 ADC 原始读数，算出 `uA_per_lsb`，调用 <br>stim_adc_set_calibration() | `stim adc show` 显示的 `peak_pos_uA` 和万用表读数吻合              |
| **⑥ 开启闭环**          | stim_service.h 中 `STIM_LOOP_ENABLED` 改为 `1`，重新编译                         | 观察日志中 `spi_amp` 逐步逼近目标，最终稳定不再打印                         |
| **⑦ 闭环调参**          | 根据响应速度/超调/抖动调整 `K_i`、`TOLERANCE`、`MAX_STEP`                              | 目标电流在 1~2 秒内平滑到达，无明显超调，稳态后无抖动                           |

**核心原则：每一层通过了再往上走，绝不跳级。** 这样一旦出问题，你能立刻定位是哪一层的锅。这就是嵌入式开发中最经典的"自底向上分层验证"策略。
