# 1.关闭桌面服务后投到屏幕上
## 1.1 关闭桌面服务
```c
systemctl stop lightdm 
systemctl stop weston
systemctl stop gdm3
```
systemctl 用来管理后台进程的命令，杀的这三个都是常见的桌面显示管理器
## 1.2推流
```c
gst-launch-1.0 v4l2src device=/dev/video-camera0 ! video/x-raw,format=NV12,width=2112,height=1568 ! kmssink
```
gst-launch-1.0是GStreamer框架的工具，用来在命令行中处理音视频管道
1.v4l2src 代表 Video for Linux 2 Sourc 
- `device=/dev/video-camera0`：告诉源头去哪个硬件节点抽水（就是我们之前确认的 RKISP 处理完的输出节点）。
2.`!`：**连接符（管道接头）**。它的作用是把前面模块吐出来的数据，无缝衔接喂给后面的模块。
3.`video/x-raw,format=NV12,width=2112,height=1568`：**能力过滤器（Caps Filter）**。摄像头其实支持好几种分辨率，这个过滤网的作用是“强制规定”，要求源头必须吐出**未经压缩的裸流 (`video/x-raw`)**，且像素排列必须是 `NV12`，分辨率必须被锁定在 `2112x1568`。
4.`kmssink`：**终点（Sink）**。KMS 的全称是 Kernel Mode Setting。这是一个非常底层的显示插件，它完全无视系统中是否安装了任何桌面 UI，直接把收到的像素数据砸到底层的 DRM（Direct Rendering Manager）显示驱动的显存里，然后点亮物理屏幕。
# 窗口模式
```c
# 声明环境变量，告诉终端您的桌面大管家在哪里

export XDG_RUNTIME_DIR=/run/user/0

export WAYLAND_DISPLAY=wayland-0

# 使用 waylandsink 并在中间加上 videoconvert 让 CPU 帮忙适配一下画幅

gst-launch-1.0 v4l2src device=/dev/video-camera0 ! video/x-raw,format=NV12,width=2112,height=1568 ! videoconvert ! waylandsink
```
