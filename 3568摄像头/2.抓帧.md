# 抓raw
`v4l2-ctl -d /dev/video-camera0 --stream-mmap=3 --stream-count=1 --stream-to=/tmp/frame.nv12`
### 1.v4l2-ctl 是 V4L2 调试工具。
### 2.-d /dev/video-camera0
表示指定操作哪个视频设备。
### 3.--stream-mmap=3
不是代表抓三帧，而是代表用mmap方式采集视频流，并且申请3个缓冲区buffer
mmap大概就是一块缓冲区，显示应用程序交给驱动，然后驱动把图像写入，然后应用程序再从这块buffer取出。也就是能把内核的缓冲区映射到用户态地址空间供应用程序使用，就不用拷贝了
### 4.--stream-count=1
这个才表示抓几帧
### 5.--stream-to=/tmp/frame.nv12
保存的是raw NV12 frame
有Y和UV平面，Y代表亮度大小是width * height，UV代表色度大小 = width * height / 2
所以一帧大小是width * height * 1.5字节
## 查看大小
ls -lh /tmp/frame.nv12
# 转成png
ffmpeg -f rawvideo -pix_fmt nv12 -s 2112x1568 -i /tmp/frame.nv12 /tmp/frame.png
