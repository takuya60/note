# 物理光学复习讲义：第三讲（第13章 光的衍射）- 详尽进阶版

> [!TIP]
> **本讲说明**：衍射是干涉的“进阶版”。干涉是“几束有限的光”在叠加，而衍射是“无数束子波”在叠加。本章的公式看起来很吓人（带积分），但**期末考试绝不考复杂的积分推导**！考试的重点是让你判断**发生了什么衍射**，以及几个**典型孔（单缝、圆孔、光栅）的条纹长什么样**。

---

## 模块一：衍射的基础与分类

为什么光能绕过障碍物跑到阴影里去？因为光是波。

### 1. 惠更斯-菲涅耳原理（核心概念）
这是解释一切衍射现象的祖师爷原理。
- **惠更斯说**：波面上的每一个点，都可以看作是一个发出“次波（球面波）”的新波源。
- **菲涅耳补充**：这些无数个次波在空间某一点相遇时，会发生**相干叠加（干涉）**。这就是衍射的本质！

### 2. ☆ 两种衍射的区别（【必考简答/判断题】）
这是考试必问的概念题：用什么近似？什么情况下发生什么衍射？

| 衍射类型 | 菲涅耳衍射 (Fresnel) | 夫琅禾费衍射 (Fraunhofer) |
| :--- | :--- | :--- |
| **物理环境** | 障碍物离光源或屏幕**很近**。 | 障碍物离光源和屏幕**无限远**（通常用透镜实现）。 |
| **波前形状** | 球面波照射，屏幕上接收的也是球面波。 | **平面波**照射，屏幕上接收的也是**平面波**。 |
| **数学近似** | 保留了距离展开式的**二次项**。 | 只保留了距离展开式的**一次项**（线性近似）。 |
| **条纹特点** | 边缘有条纹，中心可能是亮也可能是暗。 | 条纹非常规律，形状与孔的形状直接相关。 |

## 模块二：夫琅禾费衍射的典型孔径（大题与填空）

期末考 90% 的衍射题都在考“夫琅禾费衍射”，因为它好算。以下是三个必须掌握的孔径：

### 1. 单缝衍射
光穿过一条细长的缝隙。
- **现象**：中间一条极宽、极亮的“中央主极强”，两边是对称的、越来越暗的副极强。
- **暗纹条件（必背公式）**：$$ a \sin\theta = m\lambda \quad (m = \pm 1, \pm 2, \dots) $$
  *(注意这里的 $a$ 是缝宽！不要和杨氏双缝的 $d$ 搞混了！杨氏双缝算的是明纹，单缝算的是暗纹！)*
- **中央亮纹半角宽度**：$\Delta\theta_0 = \lambda / a$。
  - **【填空易考】**：缝越窄（$a$ 越小），衍射现象越明显，中央亮纹越**宽**！

### 2. 圆孔衍射与光学仪器分辨率
光穿过一个圆孔。
- **现象**：产生一个叫**爱里斑 (Airy Disk)** 的明亮中心圆斑，外面是一圈圈暗弱的圆环。
- **爱里斑角半径（必背公式）**：$$ \Delta\theta_0 = 1.22 \frac{\lambda}{D} $$
  *(这里 $D$ 是圆孔直径，那个 1.22 是贝塞尔函数算出来的常数，记住就行)*
- **瑞利判据（分辨率）**：两个点光源靠得多近时，我们还能分辨出它们是两个点？
  - 当一个点光源的爱里斑中心，恰好落在另一个点光源的爱里斑第一暗环上时，刚刚好能分辨。
  - **【填空考点】提高显微镜/望远镜分辨率的方法**：由公式可知，要么增大镜头直径 $D$，要么减小波长 $\lambda$（比如用紫外光甚至电子显微镜）。

### 3. ☆ 多缝衍射（光栅衍射）—— 大题核心
把无数条单缝等距离排列起来，就成了**光栅**（缝宽为 $a$，不透光部分宽为 $b$，光栅常数 $d = a + b$）。
- **条纹形成原理（非常重要）**：
  光栅的条纹是**单缝衍射**和**多缝干涉**两人“合作”的结果。
  - **干涉因子**：决定了哪里出现极亮的主明纹。（干涉起主导作用）
  - **衍射因子**：决定了这些明纹到底有多亮。（单缝衍射相当于一个“包络线”，框住了干涉条纹的最高亮度）。

- **光栅方程（主明纹条件，必背）**：
  $$ d \sin\theta = m\lambda $$
  *(只要满足这个条件，就会出现极其明亮的光栅谱线)*

- **缺级现象（【大题/填空必考坑点】）**：
  当本来应该出现“干涉主明纹”的地方，刚好碰上了“单缝衍射的暗纹”，这个主明纹就**消失了**，这叫**缺级**！
  - **发生条件**：如果光栅常数 $d$ 是缝宽 $a$ 的整数倍（即 $d = k \cdot a$），那么第 $k, 2k, 3k\dots$ 级主明纹就会缺级！
  - *考试神操作：如果题目说第3级缺级，立刻就能写出 $d = 3a$！*

## 模块三：【填空与判断】高频防坑指南

1. **衍射与波长的关系**：波长越长（比如红光），衍射现象越明显，条纹越宽。所以雾霾天用黄红光做红绿灯，就是因为红光衍射能力强，能绕过雾霾颗粒。
2. **单缝暗纹与双缝明纹公式混淆**：
   - 杨氏双缝明纹：$d \sin\theta = m\lambda$ （$d$ 是缝间距）。
   - 单缝衍射暗纹：$a \sin\theta = m\lambda$ （$a$ 是缝宽度）。
   - *千万别把暗纹当明纹算！*
3. **分辨率陷阱**：问“什么是最小分辨角”，填 $\Delta\theta_0 = 1.22 \lambda / D$。问“分辨率是什么”，填分辨角的倒数（$R = 1 / \Delta\theta_0$）。分辨角越小，分辨率越**高**！
4. **菲涅耳与夫琅禾费的区别陷阱**：如果题目问“只保留到二次项近似的是什么衍射？” 选**菲涅耳衍射**。
5. **光栅衍射成因陷阱**：判断题“光栅衍射条纹纯粹是衍射造成的”——**错！** 它是多缝干涉和单缝衍射**共同作用**的结果！

如果这几个孔径（单缝、圆孔、光栅）的公式您已经熟记于心，那衍射这块骨头就算啃下来了。准备好后，我们随时进入最后一章——极度抽象但也极具魅力的**偏振**！
