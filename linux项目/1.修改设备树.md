设备树位置
`kernel6.1/arch/arm/boot/dts/vanxoak-hd-rk3506-evm-v1.dts`
```c
&spi0 {
	status = "okay";

	stm32_amp: stm32-amp@0 {
		compatible = "stm32-amp";
		reg=<0>;
		spi-max-frequency = <1000000>;
		status = "okay";
		// GPIO0 PB0 下降沿中断
		interrupt-parent = <&gpio0>;
		interrupts = <RK_PB0 IRQ_TYPE_EDGE_FALLING>;
		pinctrl-names = "default";
        pinctrl-0 = <&stm32_drdy_irq_pin>;
	};

};

&pinctrl {
    stm32-amp-irq {
        stm32_drdy_irq_pin: stm32-drdy-irq-pin {
            /* 参数解析：
               1       : 代表 GPIO1
               RK_PD0  : 代表 Port D 的第 0 个引脚 (即 GPIO0_B0)
               RK_FUNC_GPIO : 强制复用为普通 GPIO 功能
               &pcfg_pull_up: 开启内部上拉电阻 (极度重要！)
            */
            rockchip,pins = <0 RK_PB0 RK_FUNC_GPIO &pcfg_pull_up>;
        };
    };
};
```
*修改设备树的时候，一定要注意分号 不然编译的时候出现如下错误*
`Error: arch/arm/boot/dts/vanxoak-hd-rk3506g-evm-nand-v1.dts:83.3-4 syntax error`
