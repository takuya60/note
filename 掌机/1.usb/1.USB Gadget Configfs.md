# 一.Configfs的使用
configfs是一个文件系统，与sysfs不同，他们同时存在
configfs是基于内存RAM的虚拟文件系统 常用于USB Gadget和工业IIO
`而sysfs是基于实际文件的文件系统，是有一个对象在内创建并把自己注册到sysfs，才会在sysfs中出现`
通过mkdir和rmdir创建对象，而且因为是基于内存的，所以掉电后丢失
### 1.创建Gadged实体
这里的$CONFIGFS_HOME是Configfs 虚拟文件系统的挂载点
```c
mkdir $CONFIGFS_HOME/usb_gadget/g1
cd $CONFIGFS_HOME/usb_gadget/g1
```
### 2.配置描述符
```c
// 用0x0104就行，代表linux基金会
echo <VID> > idVendor
echo <PID> > idProduct
// 版本号1.0
echo 0x0100 > bcdDevice
// 代表声明自己兼容 USB 2.0 协议
echo 0x0200 > bcdUSB

mkdir strings/0x409
echo <serial> > strings/0x409/serialnumber
echo <serial number> > strings/0x409/serialnumber
echo <manufacturer> > strings/0x409/manufacturer
echo <product> > strings/0x409/product
```
- VID与PID是设备描述符，VID是厂商识别码，PID是产品识别码。电脑就通过这两个的组合来寻找对应的驱动设备
- 0x409代表"英文"，只有在这个文件下，内核才知道你提供的字符串是什么语言
### 3.定义配置
这里定义了这个设备的配置，一个设备可以有多个配置，比如普通模式，省电模式
这里的命名规则是`/<name>.<number>` name可以是任意字符串
```c
mkdir configs/c.1
```
每种配置都需要相应的字符串，所以同样的，要为各种语言创建目录
```c
mkdir configs/c.1/strings/0x409
echo <configuration> > configs/c.1/strings/0x409/configuration
```
### 4.实例化功能
例如`mkdir functions/ncm.usb0`,这里的name有要求，比如`ncm`代表网络设备，所以内核会调用`request_module`自动加载网络设备usb驱动
```c
mkdir functions/<name>.<instance name>
```
### 5.绑定功能与配置
在创建了功能与配置之后，需要将他们进行管理，指定哪些功能在哪些配置中可用
ln指连接 -s指软链接
```c
ln -s functions/ncm.usb0 configs/c.1
```
### 6.使能
把这个设备绑定到UDC，也就是把UDC的名字写入这个gadged
这里的`<udc name>`是是 /sys/class/udc/* 中找到的名称之一
```c
echo <udc name> > UDC
// 禁用
echo "" > UDC
```

```c
#!/bin/sh

# 1. Auto-detect UDC
UDC_NAME=$(ls /sys/class/udc | head -n 1)
if [ -z "$UDC_NAME" ]; then
    echo "ERROR: No UDC hardware found in /sys/class/udc!"
    exit 1
fi
echo "Found UDC: $UDC_NAME"

# 2. Mount configfs
mount -t configfs none /sys/kernel/config 2>/dev/null

# 3. Clean up previous failed runs
if [ -d /sys/kernel/config/usb_gadget/g1 ]; then
    echo "Cleaning up old config..."
    echo "" > /sys/kernel/config/usb_gadget/g1/UDC 2>/dev/null
    rm /sys/kernel/config/usb_gadget/g1/configs/c.1/acm.usb0 2>/dev/null
    rm /sys/kernel/config/usb_gadget/g1/configs/c.1/hid.usb0 2>/dev/null
    rmdir /sys/kernel/config/usb_gadget/g1/functions/acm.usb0 2>/dev/null
    rmdir /sys/kernel/config/usb_gadget/g1/functions/hid.usb0 2>/dev/null
    rm -rf /sys/kernel/config/usb_gadget/g1/configs/c.1/strings/0x409 2>/dev/null
    rmdir /sys/kernel/config/usb_gadget/g1/configs/c.1 2>/dev/null
    rm -rf /sys/kernel/config/usb_gadget/g1/strings/0x409 2>/dev/null
    rmdir /sys/kernel/config/usb_gadget/g1 2>/dev/null
fi

# 4. Create new gadget
mkdir -p /sys/kernel/config/usb_gadget/g1
cd /sys/kernel/config/usb_gadget/g1

echo 0x1d6b > idVendor
echo 0x0104 > idProduct
echo 0x0100 > bcdDevice
echo 0x0200 > bcdUSB

mkdir -p strings/0x409
echo "Rockchip" > strings/0x409/manufacturer
echo "Smart Desk Gadget" > strings/0x409/product
echo "20240101" > strings/0x409/serialnumber

mkdir -p configs/c.1/strings/0x409
echo "Composite Device" > configs/c.1/strings/0x409/configuration
echo 250 > configs/c.1/MaxPower

# 5. Create ACM (Serial)
mkdir -p functions/acm.usb0
ln -s functions/acm.usb0 configs/c.1/

# 6. Create HID (Volume Control)
mkdir -p functions/hid.usb0
echo 1 > functions/hid.usb0/protocol
echo 1 > functions/hid.usb0/subclass
echo 1 > functions/hid.usb0/report_length
echo -ne \\x05\\x0c\\x09\\x01\\xa1\\x01\\x15\\x00\\x25\\x01\\x09\\xe9\\x09\\xea\\x09\\xe2\\x75\\x01\\x95\\x03\\x81\\x02\\x75\\x05\\x95\\x01\\x81\\x03\\xc0 > functions/hid.usb0/report_desc
ln -s functions/hid.usb0 configs/c.1/

# 7. Bind to UDC
echo $UDC_NAME > UDC
if [ $? -eq 0 ]; then
    echo "SUCCESS: Gadget activated on $UDC_NAME"
else
    echo "ERROR: Failed to bind to UDC. Still busy?"
fi
```
