## 1.buildroot修改
### libpng
勾选BR2_PACKAGE_LIBPNG
这个是pcsx需要的
### libsdl
开启libSDL-1.2，这里是因为pcsx模拟器依赖的是sdl1的库
如果开发板内存足够，我们也可以选用性能更好的sdl12-compat
sdl12-compat的接口和sdl1兼容，但是实际上用的底层是sdl2，可以开启OpenEGL，X11，DRM啥的那些高级配置，但是别忘了开启sdl2的DRM前需要去开启mesa3d
`这里注意一下sdl2不能开framebuffer，所以没有X11/Wayland或者DRM啥的，会直接变成dummy`
因为我的开发板只有128mb内存，所以我就选用sdl1.2的framebuffer了
我们需要开启
SDL_VIDEO_DRIVER_FBCON

## 2.kernel修改
因为sdl1是必须需要Virtual terminal的，所以我们需要开启虚拟终端
进入 `Device Drivers` -> `Character devices`
打开`Support for console on virtual terminal`
然后开启framebuffer控制台映射
进入 `Device Drivers` -> `Graphics support` -> `Console display driver support` 勾选 `Framebuffer Console support`

## 2.1(可选) 增加内存
如果你也用的是rk3506g，可以去设备树里面找到这里。这个是视频硬解码分配的22mb内存，如果用不到这个功能，就分配的少一些，能多一些内存
```c
&cma {
size = <0x1600000>;
};
```
把0x1600000改成0x200000
## 3.对模拟器代码的修改
修改模拟器下`frontend/plat_sdl.c`
找到下面这一段
```c
 SDL_PumpEvents();

plat_sdl_screen = SDL_SetVideoMode(set_w, set_h, 16, flags);

    //printf("mode: %dx%d %x -> %dx%d\n", set_w, set_h, flags,

    //  plat_sdl_screen->w, plat_sdl_screen->h);

    assert(plat_sdl_screen);
```
因为我们的屏幕是320x240，而有的游戏画面是640x480，所以运行的时候会报错
`pcsx: unhandled page fault (11) at 0x00000010, code 0x005`
所以我们把上面的代码改一下
```c
SDL_PumpEvents();

    set_w = 320;
    set_h = 240;
    
    flags &= ~SDL_HWSURFACE; // 剔除硬件画布请求，防止硬件不支持导致返回 NULL
    flags &= ~SDL_DOUBLEBUF; // 剔除容易引发兼容问题的双重缓冲
    flags |= SDL_SWSURFACE;  // 强制要求在普通内存里开辟软件画布
    flags |= SDL_ANYFORMAT;  // 论屏幕真实色深是多少，都强制适配

    plat_sdl_screen = SDL_SetVideoMode(set_w, set_h, 16, flags);

    if (plat_sdl_screen == NULL) {
        printf("\n[FATAL ERROR] SDL_SetVideoMode failed: %s\n\n", SDL_GetError());
        exit(1); 
    }
```

## 4.模拟器启动配置
```c
# 1. 确保你现在在 TF 卡的挂载目录下
cd /mnt/sdcard

# 2. 在系统的根目录下，创建它心心念念的隐藏文件夹和 bios 文件夹
mkdir -p /.pcsx/bios

# 复制真实 BIOS 文件
cp bios/scph1001.bin /.pcsx/bios/

# 强制生成配置文件
echo "Bios = scph1001.bin" > /.pcsx/pcsx.cfg
```
