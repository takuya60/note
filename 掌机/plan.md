# 3506G 综合实战项目：双模式智能桌搭与复古掌机

## 一、 项目总体架构设计

本项目旨在将一块基于 3506G 芯片的开发板，打造成一个具备两种工作形态的 USB 复合外设设备。

1. **桌搭模式 (PC 副屏与控制器)**：
    
    - 开发板通过 USB 插入电脑，系统将其识别为**键盘（USB HID）**和**串口（USB CDC-ACM）**。
        
    - 电脑后台运行 Python 脚本，通过虚拟串口将 CPU、内存、温度等硬件状态实时发送给开发板。
        
    - 开发板屏幕通过 **LVGL** 绘制出极具科技感的仪表盘界面。
        
    - 旋转开发板上的 EC11 旋钮，直接通过硬件级 USB HID 协议控制电脑音量，无需电脑端安装额外驱动。
        
2. **掌机模式 (独立娱乐终端)**：
    
    - 随时按下开发板上的“模式切换”物理按键。
        
    - 开发板后台主控程序暂停桌搭界面的渲染，并拉起一个轻量级的复古游戏模拟器（如 NES/FC）。
        
    - 屏幕和按键的控制权无缝移交给模拟器，变成一台掌机。退出游戏后，瞬间恢复为桌搭状态。
        

---

## 二、 硬件需求清单 (BOM)

- **核心板**：3506G 开发板（需引出 USB OTG 接口、多组 GPIO、SPI 总线）。
    
- **显示与触控**：SPI TFT LCD 屏幕（建议分辨率 320x240，ST7789 或 ILI9341 驱动芯片）+ 贴合的 SPI/I2C 触摸屏（XPT2046 等）。
    
- **输入设备**：
    
    - EC11 旋转编码器（带按下功能，需占用 3 个 GPIO 中断引脚）。
        
    - 至少 5 个机械按键（十字方向键 + 模式切换键，接 GPIO）。
        
- **音频输出**：I2S DAC 模块或板载音频芯片（用于掌机模式发声）。

## 三、 分阶段详细实施计划与验收标准

本项目分为六个核心阶段，建议严格按照顺序推进，前置依赖不解决，切勿跳步。

### 阶段一：系统基石 —— 构建极简 Linux 环境 (预计耗时：1-2周)

本阶段的目标是抛弃现成的臃肿系统，从源码编译一个专为该项目定制的精简操作系统。

- **具体任务**：
    
    1. 在宿主机（Ubuntu）上安装交叉编译工具链（Cross-Toolchain）。
        
    2. 使用 **Buildroot** 配置系统架构（`make menuconfig`），选择对应的 ARM 核心。
        
    3. 配置并编译 U-Boot（引导程序）和 Linux Kernel 源码。
        
    4. 在 Buildroot 菜单中勾选项目必备的调试工具：`evtest`（查按键）、`tslib`（校准屏幕）、`alsa-utils`（测声音）、`htop`（看系统资源）。
        
    5. 生成 `rootfs.ext4` 根文件系统，并打包烧录进开发板的 eMMC 或 SD 卡。
        
- **验收标准**：给开发板上电，通过串口线连接电脑，能在终端软件（如 MobaXterm/Putty）中看到系统启动日志，并成功进入 `root@buildroot:~#` 命令行。
    

### 阶段二：视觉与触觉 —— 攻克 SPI 与输入驱动 (预计耗时：2-3周)

这是本项目最硬核的底层驱动阶段，让 Linux 认识你的外设。

- **具体任务**：
    
    1. **配置设备树 (Device Tree - DTS)**：修改源码中的 `.dts` 文件，将 SPI 屏幕、触摸IC、EC11 旋钮、普通按键映射到对应的硬件引脚上。
        
    2. **点亮屏幕**：在内核 `make menuconfig` 中开启 `fbtft` 驱动框架和对应的屏幕芯片驱动。**至关重要**：必须开启 SPI 驱动的 **DMA (直接内存访问)** 支持，否则后续跑游戏会卡顿。
        
    3. **打通输入子系统**：编写或配置 EC11 旋钮的旋转解码驱动（A/B相电平解析），配置 `gpio-keys` 将按键注册为标准的 Linux 输入事件。
        
    4. **屏幕校准**：运行 Buildroot 编译好的 `ts_calibrate`，点击屏幕五个准星，生成触摸校准文件。
        
- **验收标准**：
    
    - 屏幕：终端输入 `cat /dev/urandom > /dev/fb0`，屏幕瞬间布满彩色雪花点。
        
    - 输入：终端输入 `evtest`，拧动旋钮或按下按键时，终端能实时打印出对应的键值（如 `REL_WHEEL` 或 `KEY_A`）。
        

### 阶段三：连接双端 —— USB 设备模拟与通信打通 (预计耗时：1-2周)

让开发板通过一根 USB 线，同时扮演两种身份。

- **具体任务**：
    
    1. 在 Linux 内核中开启 **USB Gadget** 和 **ConfigFS** 支持。
        
    2. 编写一个 Shell 脚本（放在 `/etc/init.d/` 开机自启），利用 ConfigFS 将 USB 接口虚拟成一个**复合设备 (Composite Device)**。
        
    3. 挂载功能 1：`usb_f_hid`（模拟多媒体键盘，定义 Report Descriptor 支持音量加减）。
        
    4. 挂载功能 2：`usb_f_acm`（模拟串口 `/dev/ttyGS0`，用于接收电脑数据）。
        
- **验收标准**：
    
    把开发板插上电脑，Windows 的“设备管理器”里同时多出一个“USB 输入设备（键盘）”和一个“USB 串行设备 (COMx)”。
    

### 阶段四：大脑运转 —— 后台守护进程与桌面 UI (预计耗时：2周)

软硬结合的阶段，编写应用程序让设备真正活起来。

- **具体任务**：
    
    1. **PC 端伴侣软件 (Python)**：利用 `psutil` 读取电脑状态，打包成 JSON 格式，通过 `pyserial` 发送到刚才生成的 COM 接口。
        
    2. **开发板主控程序 (C/C++)**：
        
        - **UI 线程**：移植 **LVGL** 图形库，对接 `/dev/fb0` 和 `tslib`，设计极客风的仪表盘、进度条。
            
        - **串口解析线程**：阻塞读取 `/dev/ttyGS0`，解析 JSON 数据，并调用 LVGL 的 API 刷新界面指针。
            
        - **旋钮监听线程**：读取旋钮的 `evtest` 节点，一旦检测到旋转，立刻向底层 USB HID 节点写入数据，实现控制电脑音量，并在 LVGL 上弹窗显示音量条。
            
- **验收标准**：不需要鼠标键盘，开发板插上电脑后自动亮起仪表盘；电脑 CPU 占用率变化时，开发板仪表的指针实时跟随转动；拧旋钮，电脑音量直接加减。
    

### 阶段五：掌机蜕变 —— 状态机切换与模拟器集成 (预计耗时：1-2周)

实现“工作”与“娱乐”的跨界。

- **具体任务**：
    
    1. 在 Buildroot 中交叉编译一个轻量级游戏模拟器（例如基于 SDL 库的 NES 模拟器）。使用前一阶段提过的 `alsa-utils` 确保音频输出正常。
        
    2. **编写状态切换逻辑**：主控程序监听“模式切换键”。
        
        - 按下时：主控程序调用 LVGL 暂停渲染 API -> 释放对 Framebuffer 和输入设备的占用 -> 使用 `fork()` 和 `exec()` 系统调用，拉起游戏模拟器进程。
            
        - 退出时：模拟器通过组合键退出，主控程序检测到子进程结束，重新接管屏幕，恢复 LVGL 桌搭界面。
            
- **验收标准**：按下按键，画面从电脑状态监控瞬间切入《超级玛丽》标题界面，按键控制灵敏无延迟且有声音；退出游戏后立刻变回监控面板。
    

### 阶段六：极致打磨 —— 系统裁剪与秒级启动 (预计耗时：1周)

将这个“开发板”彻底包装成一个成熟的“数码外设”。

- **具体任务**：
    
    1. **内核瘦身**：重新执行 `make menuconfig`，砍掉 3506G 默认配置中一切不需要的模块（如 IPv6、无线网卡、EXT4以外的文件系统），大幅缩小内核体积。
        
    2. **砍掉等待**：修改 U-Boot 环境变量 `bootdelay=0`。
        
    3. **静默启动**：在内核启动参数 `bootargs` 中加入 `quiet`，关闭所有的内核打印信息。替换 Linux 默认的企鹅 Logo，换成你的自定义开机画面。
        
- **验收标准**：开发板插上电脑 USB 供电后，屏幕直接点亮显示开机图，并在 3 到 5 秒内无缝切入 LVGL 桌搭监控界面，全程看不到任何一行代码。
