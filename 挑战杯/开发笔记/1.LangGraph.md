一个agent有三个核心概念
- State 全局状态
- Node 节点 表示某个 Agent 或函数
- Edge：边，也就是节点之间怎么流转
# 1.State
state是全局可见的，所有agent都可以进行读写
比如这是一个state
```python
class MLPlatformState(TypedDict):
      learner_profile: dict
      target_algorithm: str

      diagnosis: dict
      retrieved_knowledge: list
      generated_resources: dict

      review_result: dict
      reviewer_feedback: str
      is_passed: bool

      feedback: dict
      final_report: dict
```
学情诊断 Agent      读：learner_profile，target_algorithm
				写：diagnosis
知识检索 Agent      读：diagnosis，target_algorithm
				写：retrieved_knowledge
资源生成 Agent      读：diagnosis，retrieved_knowledge，reviewer_feedback
				写：generated_resources
审核 Agent             读：generated_resources，retrieved_knowledge，diagnosis
				写：review_result，reviewer_feedback，is_passed

# 2.Node
Node相当于处理步骤，相当于是一个执行特定功能的函数
```python
def diagnosis_node(state):
      # 根据 learner_profile 生成 diagnosis
      return {
          "diagnosis": diagnosis_result
      }

  def retrieval_node(state):
      # 根据 diagnosis 和 target_algorithm 检索知识库
      return {
          "retrieved_knowledge": knowledge_chunks
      }

  def generator_node(state):
      # 根据诊断和知识库生成学习资源
      return {
          "generated_resources": resources
      }
```
