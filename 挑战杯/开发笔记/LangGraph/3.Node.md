Node 本质上就是一个 Python 函数,先接收 State，然后返回 State 的部分更新
例如
```python
def diagnosis_node(state: MLTrainingState):
      learner_profile = state["learner_profile"]

      diagnosis = {
          "weak_points": ["线性代数", "模型评估指标"],
          "recommended_level": "beginner_plus",
          "strategy": "减少公式推导，增加图解和案例"
      }

      return {
          "diagnosis": diagnosis
      }
```
 Node 不需要返回完整 State，只需要返回它更新的字段， LangGraph 会自动把它合并回全局 State。
## 多个节点串联
比如有三个节点
 ```python
  def diagnosis_node(state):
      return {
          "diagnosis": {
              "weak_points": ["模型评估"],
              "recommended_level": "beginner_plus"
          }
      }

  def retrieval_node(state):
      diagnosis = state["diagnosis"]

      return {
          "retrieved_knowledge": [
              {
                  "source": "model_evaluation.md",
                  "content": "分类模型不能只看准确率，还要看召回率和 F1。"
              }
          ]
      }

  def generation_node(state):
      diagnosis = state["diagnosis"]
      knowledge = state["retrieved_knowledge"]

      return {
          "generated_resources": {
              "lecture": "这是适合初学者的模型评估讲义。",
              "practice": "使用 sklearn.metrics 计算 accuracy、recall、f1。",
              "quiz": ["为什么准确率可能误导判断？"]
          }
      }
 ```
 调用 LangGraph提供的API 连接,这里具体解释见Edge的笔记
 ```python
 from langgraph.graph import StateGraph, START, END

  builder = StateGraph(MLTrainingState)

  builder.add_node("diagnosis", diagnosis_node)
  builder.add_node("retrieval", retrieval_node)
  builder.add_node("generation", generation_node)

  builder.add_edge(START, "diagnosis")
  builder.add_edge("diagnosis", "retrieval")
  builder.add_edge("retrieval", "generation")
  builder.add_edge("generation", END)

  graph = builder.compile()
 ```
