如果用 LangChain + Pydantic，可以定义：

  from pydantic import BaseModel
  from typing import List


  class CodeStep(BaseModel):
      step_name: str
      python_code: str
      explanation: str


  class GeneratedResources(BaseModel):
      theory_note: str
      dataset_instruction: str
      practice_guide: List[CodeStep]
      graded_quiz: List[str]

  然后：

  structured_llm = llm.with_structured_output(GeneratedResources)

  节点中调用：

  resources = structured_llm.invoke(prompt_input)

  return {
      "generated_resources": resources.model_dump()
  }

  这对你们项目非常重要。

  因为你们前端要分区展示：

  讲义
  代码
  测试题
  学习路径
  引用来源

  评测模块也要计算结构完整率。

  如果只输出一整段 Markdown，后续会很难处理。ni
