让节点执行后直接指定下一步去哪里。
```python
  from langgraph.types import Command


  def review_node(state) -> Command:
      if state["is_passed"]:
          return Command(
              update={"review_result": {"passed": True}},
              goto="feedback"
          )
      else:
          return Command(
              update={"review_result": {"passed": False}},
              goto="generation"
          )
```
  它把两件事合在一起： 更新 State,决定跳转节点
