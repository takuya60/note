```python
from typing import TypedDict, List, Dict, Any

class MLTrainingState(TypedDict):
      learner_profile: Dict[str, Any]
      target_skill: str

      diagnosis: Dict[str, Any]
      retrieved_knowledge: List[Dict[str, Any]]
      generated_resources: Dict[str, Any]

      review_result: Dict[str, Any]
      reviewer_feedback: str
      is_passed: bool

      feedback_decision: Dict[str, Any]
      agent_events: List[Dict[str, Any]]
      retry_count: int
```
  ┌─────────────────────┬─────────────────────────────┐
  │        字段         │            作用             │
  ├─────────────────────┼─────────────────────────────┤
  │ learner_profile     │ 学习者画像                  │
  ├─────────────────────┼─────────────────────────────┤
  │ target_skill        │ 学习目标，如逻辑回归        │
  ├─────────────────────┼─────────────────────────────┤
  │ diagnosis           │ 学情诊断结果                │
  ├─────────────────────┼─────────────────────────────┤
  │ retrieved_knowledge │ RAG 检索到的知识            │
  ├─────────────────────┼─────────────────────────────┤
  │ generated_resources │ 生成的讲义、代码、题目      │
  ├─────────────────────┼─────────────────────────────┤
  │ review_result       │ 审核结果                    │
  ├─────────────────────┼─────────────────────────────┤
  │ reviewer_feedback   │ 审核修改意见                │
  ├─────────────────────┼─────────────────────────────┤
  │ is_passed           │ 是否审核通过                │
  ├─────────────────────┼─────────────────────────────┤
  │ feedback_decision   │ 后续学习建议                │
  ├─────────────────────┼─────────────────────────────┤
  │ agent_events        │ 给前端展示的 Agent 流程日志 │
  ├─────────────────────┼─────────────────────────────┤
  │ retry_count         │ 审核失败后的重试次数        │
  └─────────────────────┴─────────────────────────────┘
