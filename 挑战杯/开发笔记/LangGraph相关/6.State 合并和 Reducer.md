
  默认情况下，如果一个节点返回：
  {
      "agent_events": [
          {"agent": "diagnosis", "summary": "完成诊断"}
      ]
  }
  下一个节点也返回：
  {
      "agent_events": [
          {"agent": "retrieval", "summary": "完成检索"}
      ]
  }
  默认可能会覆盖旧值，而不是追加。但我们希望：
  agent_events = [
      diagnosis_event,
      retrieval_event
  ]
  所以需要 reducer。
```python
from typing import Annotated, TypedDict
  import operator


  class State(TypedDict):
      agent_events: Annotated[list, operator.add]
```
意思是：agent_events 这个字段每次更新时，用 list + list 的方式合并
