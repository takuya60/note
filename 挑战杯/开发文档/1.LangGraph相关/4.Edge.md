 LangGraph 的边有两类 :普通边,条件边
## 1.普通边
 ###普通边就是固定顺序。
	  builder.add_edge("diagnosis", "retrieval")
	  builder.add_edge("retrieval", "generation")
  意思是：
  diagnosis 完成后一定进入 retrieval
  retrieval 完成后一定进入 generation
## 2.条件边
`builder.add_conditional_edges()`
```python
 def route_after_review(state: MLTrainingState):
      if state["is_passed"]:
          return "feedback"
      if state["retry_count"] >= 2:
          return "feedback"
          
      return "generation"
      
builder.add_conditional_edges(
      "review",
      route_after_review,
      {
          "generation": "generation",
          "feedback": "feedback"
      }
  )

```
