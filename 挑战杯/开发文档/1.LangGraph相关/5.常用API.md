### 1.StateGraph
创建一张状态图
```python
from langgraph.graph import StateGraph

builder = StateGraph(State)
```
### 2.START 和 END
表示图的起点和终点
```python
from langgraph.graph import START, END
builder.add_edge(START, "diagnosis")
builder.add_edge("report", END)
```
### 3.add_node
添加节点, add_node(节点名称, 节点函数)
```python
builder.add_node("generation", generation_node)
builder.add_node("review", review_node)
```
### 4.add_edge
添加普通边, 表示diagnosis 执行完后进入 retrieval
```python
builder.add_edge("diagnosis", "retrieval")
```
### 5.add_conditional_edges
添加条件边
```python
builder.add_conditional_edges(
      "review",
      route_after_review,
      {
          "regenerate": "generation",
          "feedback": "feedback"
      }
  )
```
review 执行完后，根据 route_after_review 的返回值决定下一步
### 6.compile
编译图,只有 compile 之后，图才能运行
```python
graph = builder.compile()
```
### 7.invoke
一次性运行完整图
```python
graph = builder.compile()
```
用于后端接口，一次性任务，测试
### 8.stream
流式运行图，会一边执行一边返回中间结果
```python
for event in graph.stream(initial_state):
      print(event)
```
适合 前端展示每个节点输出，演示 Agent 流程
### 9.batch
批量运行多个输入
```python
results = graph.batch([
      state1,
      state2,
      state3
  ])
```
适合评测：
  同时跑 beginner / normal / advanced 三类学习者
  比较生成结果差异
  统计覆盖率和适配
### 10.ainvoke / astream
异步运行
```python
result = await graph.ainvoke(initial_state)

  async for event in graph.astream(initial_state):
      print(event)
```
 适合：FastAPI 异步接口，WebSocket 实时返回，并发任务
