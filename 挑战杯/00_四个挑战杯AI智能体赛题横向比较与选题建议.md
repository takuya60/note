# 挑战杯 AI / 智能体候选题简明对比与推荐

## 1. 四个题目对比

| 推荐顺序 | 题目                        | 类型       | 一句话判断                         |
| ---: | ------------------------- | -------- | ----------------------------- |
|    1 | XH-202613 车路云协同管控算法与仿真平台  | 工程系统型    | 最稳，展示效果强，评分清楚，不依赖 GPU         |
|    2 | XH-202627 Intern-S1 数学智能体 | 推理智能体型   | Agent 味道强，算力门槛低，边界清楚，但依赖数学正确率 |
|    3 | XH-202631 荣耀超长程多智能体架构     | 通用智能体架构型 | 上限高，最前沿，但抽象、容易做虚、演示不稳定        |
|    4 | XH-202603 太空智算遥感大模型       | 算法模型型    | 最硬核，但需要模型训练、GPU 和国产芯片部署适配     |


### 3.1 车路云协同管控算法与仿真平台

**优点：**

- 任务清晰：仿真平台 + 交通算法 + 对比评估。
- 工具成熟：SUMO、TraCI、Python 都比较可控。
- 展示直观：车流、红绿灯、拥堵缓解、指标曲线都容易做视频。
- 不需要 GPU，也没有国产芯片部署压力。
- 评测指标明确：等待时间、排队长度、通行量、能耗等。

**风险：**

- 需要学习交通仿真。
- AI 味道相对弱，需要通过智能控制算法、云边端协同、扰动注入来增强。
- 场景搭建和演示视频会花时间。

**适合团队：**

Python 工程、系统开发、可视化能力较强，想稳妥完成并拿出漂亮演示。

---
### 3.2 Intern-S1 数学智能体

**优点：**

- 不需要训练大模型，直接调用 Intern-S1 API。
- 算力门槛低，普通电脑即可开发。
- 题目边界清楚，评分明确，正确率占 60%。
- 很贴合 AI Agent：题型路由、Solver、Verifier、Explainer、Formatter 都很自然。
- 有官方 API、lagent 基线、培训和答疑支持。

**风险：**

- 数学题难度可能较高。
- 正确率压力大。
- 需要稳定 JSON 输出，格式错会直接影响评分。
- 如果团队数学基础弱，会很难优化答案质量。

**适合团队：**

Python 能力不错，团队里有数学基础较强的人，想做 AI Agent 但不想承担训练和部署风险。

---
### 3.3 荣耀超长程多智能体架构

**优点：**

- 最贴近通用智能体前沿。
- 上限很高，适合包装成 AgentOS / 数字劳动力 / 多智能体自治引擎。
- 不依赖固定数据集，发挥空间大。
- 可以展示动态任务图、低熵通信、长程记忆、异常恢复。

**风险：**

- 题目太抽象。
- 容易做成普通 Agent demo。
- 评测指标需要自己设计。
- 演示稳定性不如车路云和数学智能体。
- 必须做出架构创新，否则很难区分于 Claude Code / Codex 类工具。

**适合团队：**

熟悉大模型 Agent、工具调用、后端架构、可视化，且愿意承担高风险冲高上限。

**一句话建议：**

> 如果没有较强 Agent 工程经验，不建议优先选荣耀题。

---

### 3.4 太空智算遥感大模型

**优点：**

- 技术含金量最高。
- 航天 + 多模态 + 星载部署，包装非常硬核。
- 评分指标明确：任务性能、资源效率、创新性。
- 如果能做出模型压缩和部署实验，竞争力很强。

**风险：**

- 需要深度学习、计算机视觉、多模态模型经验。
- 需要 GPU 资源。
- 决赛国产芯片部署适配复杂。
- 普通 API demo 不够，必须有模型、数据、指标和资源消耗分析。

**适合团队：**

有视觉模型训练经验、GPU 资源、模型压缩或部署经验的团队。

## 4. 按团队情况选题

### 如果想稳妥完成、展示效果强

选：**车路云**

原因：工具成熟、指标明确、演示直观、风险最低。

### 如果想做 AI Agent，但不想训练模型

选：**Intern-S1 数学智能体**

原因：API 模型、边界清楚、Agent 设计空间明确。

### 如果想冲智能体架构上限

选：**荣耀多智能体**

前提：团队有较强 Agent 工程能力，否则容易做虚。

### 如果想做硬核模型算法

选：**太空智算遥感大模型**

前提：有 GPU、深度学习训练经验和部署资源。

## 5. 当前推荐排序

### 第一推荐：车路云协同管控算法与仿真平台

最稳，最容易做出可运行系统和强展示。建议方案：

> 雄安窄路密网数字靶场 + 云边端协同自适应信号控制 + 自动化评估报告。

### 第二推荐：Intern-S1 数学智能体

新增后非常值得考虑。建议方案：

> 题型路由 + Solver Agent + Verifier Agent + 工具校验 + 自我修正 + 稳定 JSON 输出。

如果团队数学基础好，它可以上升为第一选择。

### 第三推荐：荣耀超长程多智能体架构

上限高，但必须做出：

> 动态任务图 + 低熵通信 + 长程记忆 + 检查点恢复 + 异常注入评测。

否则容易像普通 Agent demo。

### 第四推荐：太空智算遥感大模型

适合硬核算法团队。建议方案：

> 轻量遥感 VLM + 任务插件 + LoRA 微调 + 量化压缩 + 星载容错实验。

普通团队不建议优先选。

## 6. 最终建议

如果没有额外团队优势，我建议：

> **首选车路云，强备选 Intern-S1 数学智能体。**

如果你们团队数学能力较强，并且更想做纯 AI Agent，那么可以优先考虑 Intern-S1 数学智能体。

如果你们团队只是普通软件开发能力较强，想稳妥做出成果，那么车路云仍然更稳。
